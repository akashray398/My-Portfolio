# Akash Kumar Yadav | Portfolio

A modern, responsive portfolio website built with React + Vite, designed to showcase Android, Java, and product-focused engineering work with a premium dark aesthetic.

Live Demo:
- https://my-portfolio-nine-navy-73.vercel.app

## Overview

This portfolio highlights:
- Android development and Java engineering experience
- technical projects and product thinking
- education and certifications
- career interests and strengths
- contact details and social links

It is built to feel clean, premium, and mobile-friendly while staying easy to customize.

## Features

- Responsive single-page portfolio layout
- Premium dark minimal design
- Hero section with personal branding
- About, education, skills, projects, experience, and contact sections
- Interactive project cards and modal details
- Command palette / keyboard navigation
- Resume and contact links
- Fast Vite production build

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React Icons
- Framer Motion / Motion
