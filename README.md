# AKASH.DEV

Premium developer portfolio for Akash Kumar Yadav, built with React, Vite, Motion, Lucide React, and custom responsive CSS.

## Run locally

```bash
npm install
npm run dev
```

Create a production bundle with `npm run build` and preview it with `npm run preview`.

## Personalization

Update links, email, role, project content, skills, experience, and certifications in `src/data/site.js`. The contact form is intentionally UI-only until an email service is connected. Replace the canonical URL in `index.html` with the deployed domain before launch.

## Interaction notes

- `Ctrl/Cmd + K` opens the command palette.
- `G` opens GitHub, `R` scrolls to contact, and `P` scrolls to projects.
- Project cards open animated case-study modals.
- Reduced-motion preferences are respected.
